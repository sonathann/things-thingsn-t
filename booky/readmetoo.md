# booky ✦

### beauty, wellness, appointments, and a concerning amount of debugging.

**booky** is a mobile app i've been working on for a while now. it's basically a place where people can find salons, discover specialists, book appointments, and manage their beauty & wellness stuff without having to call 17 different people.

built with flutter, dart, supabase, and a questionable amount of caffeine.

**status:** still cooking.

---

## so, what does it do?

booky has two sides. one for people looking for services, and another for businesses trying to manage everything without losing their minds.

### for customers

- find salons and independent specialists
- browse services, prices, and profiles
- book appointments
- discover places nearby
- manage upcoming bookings
- get notifications about appointments

### for salons & specialists

- create and customize business profiles
- manage services, staff, and schedules
- handle incoming appointments
- set availability
- manage business information
- generally keep things organized

## what did i actually do?

pretty much started this whole thing from scratch.

came up with the idea, designed the UI/UX, figured out how everything should work, and started building it.

some of the things i've been doing:

- designing screens and figuring out user flows
- defining features and how they're supposed to behave
- working on the Flutter/Dart code
- manually testing pretty much everything i can get my hands on
- finding bugs, fixing some, creating new ones probably
- migrating and managing the entire Supabase backend
- making technical decisions and figuring out what to build next
- working with a much more experienced developer who occasionally saves me from my own decisions
- using AI tools along the way, because it's 2026 and why wouldn't i?

## breaking things (QA)

a pretty big part of this project has been testing.

lots of clicking around, trying things that probably shouldn't be tried, finding weird behavior, reproducing bugs, and figuring out why something that worked yesterday suddenly doesn't work today.

some of the testing includes:

- authentication and account flows
- business registration and onboarding
- permissions and user roles
- booking logic
- profile and image management
- UI behavior and navigation
- regression testing after changes

there are also automated Flutter tests and some documented test scenarios.

i'll be adding actual test cases, bug reports, and other QA-related stuff here.
